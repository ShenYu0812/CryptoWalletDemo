| 字段名                       | 业务含义                                             | 使用场景                                                         |
|---------------------------|--------------------------------------------------|--------------------------------------------------------------|
| coin_id                   | 代币的唯一标识代码，如“BTC”代表比特币，“ETH”代表以太坊                 | 用于在钱包或相关系统中精准识别和区分不同的代币，在进行代币交易、查询余额、转账等操作时作为关键标识符           |
| name                      | 代币的全称，“Bitcoin”（比特币）、“Ethereum”（以太坊）             | 在界面展示、信息介绍等场景，向用户直观展示代币的名称，增加辨识度                             |
| symbol                    | 代币的交易符号，简洁标识，如“BTC”“ETH”                         | 在交易界面、资产列表展示中，方便用户快速识别代币，也用于交易对表示，像“BTC/USD”“ETH/BTC”        |
| token_decimal             | 代币的小数位数，决定最小可分割单位，比特币8位，意味着最小单位精确到0.00000001 BTC | 在进行代币数量显示、计算交易金额、余额等场景时，用于确定数字的精度和展示格式                       |
| contract_address          | 代币合约地址，在以太坊区块链上ERC20代币的合约地址，若不是ERC20代币则为空        | 用于与智能合约交互，如查询代币余额、发起代币转账等操作，通过合约地址定位并调用合约的相应功能               |
| withdrawal_eta            | 代币提现预计时间，是一个包含不同时间估计的列表                          | 在用户发起提现操作时，向用户展示提现可能完成的时间范围，帮助用户预估资金到账时间                     |
| colorful_image_url        | 代币彩色图标URL链接                                      | 在钱包界面或相关应用中，展示代币的彩色图标，增强视觉效果和辨识度                             |
| gray_image_url            | 代币灰色图标URL链接                                      | 通常用于不可用状态、未选中状态或特定主题下的图标展示                                   |
| has_deposit_address_tag   | 表示存入代币时是否需要额外的地址标签                               | 在用户进行代币存入操作时，判断是否需要提示用户输入额外的地址标签信息                           |
| min_balance               | 代币的最小余额限制，为0表示无限制                                | 在用户进行提现、转账等操作时，检查用户的代币余额是否满足最小余额要求，防止余额不足的错误操作               |
| blockchain_symbol         | 代币所属区块链的符号，如“BTC”代表比特币区块链，“ETH”代表以太坊区块链          | 用于明确代币所属的区块链网络，在进行跨链操作、区块链相关设置或信息展示时使用                       |
| trading_symbol            | 代币在交易市场中的交易符号，与symbol字段类似                        | 在交易平台、行情显示等场景，用于标识交易对中的代币，方便用户进行交易操作和查看行情                    |
| code                      | 代币的代码，与coin_id或symbol类似，用于简洁标识代币                 | 在系统内部代码逻辑、数据存储和处理中，作为代币的标识符，提高数据处理效率                         |
| explorer                  | 代币交易的区块链浏览器链接，通过该链接可查询交易详情                       | 当用户想要查看代币的交易记录、区块信息等详细内容时，提供便捷的区块链浏览器入口                      |
| is_erc20                  | 表示代币是否为以太坊ERC20标准代币                              | 在进行代币相关操作时，根据此标志判断是否按照ERC20标准的规则进行处理，如转账、余额查询等操作的实现方式        |
| gas_limit                 | 代币交易时所需的Gas限制，Gas是以太坊网络交易费用的计量                   | 在进行以太坊网络上的代币交易操作时，设置交易的Gas限制，防止因Gas不足导致交易失败，也影响交易手续费的计算      |
| token_decimal_value       | 代币小数位对应的数值，用于计算和展示                               | 在进行代币数量的计算、格式化展示以及与其他系统交互时，作为精确计算的基础                         |
| display_decimal           | 代币在界面上显示的小数位数                                    | 在钱包界面展示代币余额、交易金额等信息时，确定数字的显示精度，提高用户体验                        |
| supports_legacy_address   | 表示是否支持旧版钱包地址格式                                   | 在用户进行地址相关操作时，如转账、导入钱包等，判断是否支持旧版地址格式，避免因地址格式问题导致操作失败          |
| deposit_address_tag_name  | 存入地址标签的名称（若有）                                    | 当has_deposit_address_tag为true时，在界面上提示用户输入地址标签时使用，告知用户标签的具体含义 |
| deposit_address_tag_type  | 存入地址标签的类型（若有）                                    | 用于确定地址标签的格式和验证规则，确保用户输入的地址标签符合要求                             |
| num_confirmation_required | 代币交易所需的确认次数                                      | 在进行代币交易操作后，用于提示用户需要等待的确认次数，确保交易的安全性和可靠性，确认次数达到后交易才被视为有效完成    |
